Turns observed traffic into ready-to-paste block rules. Pick the dimension that best separates the traffic you want gone from the traffic you want to keep, review the list, deselect false positives, then copy the rule for your firewall or web server. These are suggestions — you apply them, at your own discretion.

How to use this
  1. Pick a dimension. Each tab below matches traffic a different way. The one to choose is whichever isolates the unwanted traffic with the fewest real visitors caught alongside it — see the note under each tab.
  2. Tune the filters. The toolbar controls re-query the server, so the table always reflects the window currently loaded, not a cached view.
  3. Review every row. Rows are selected by default. Untick anything you recognise — a partner crawler, your own monitoring, a shared university or corporate gateway.
  4. Choose a format and copy. The note under the output explains what that format needs and where it goes. Apply it, then watch this dashboard to confirm the traffic actually stopped.

A block you cannot explain later is a block you will never dare remove. Note why you added each one.
